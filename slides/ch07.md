# 7.1 声音的数字化

## 声音是什么
- 物体**振动**，带动空气一疏一密地传出去
- **频率**：每秒振动多少次，决定音调高低
- **振幅**：振动幅度，决定声音响不响
- **波形**：空气压力随时间变化的曲线

::: notes
人耳大约能听到 20～20 000 赫兹的声音。
:::

## 采样与量化
| 采样率 | 能保留的最高频率 | 用在哪里 |
|---|---|---|
| 8000 赫兹 | 4000 赫兹 | 传统电话，发闷 |
| 16 000 赫兹 | 8000 赫兹 | 语音识别最常用 |
| 44 100 赫兹 | 22 050 赫兹 | CD 音乐 |

- **采样率至少是最高频率的两倍**

::: notes
采样：每隔一段时间记录一次信号大小。量化：用有限个等级表示每次的数值，16 位有 65 536 个等级，位数越多越精细。
:::

## 算一算：一段录音有多大
- 16 000 赫兹、16 位、单声道
- 每秒：16 000 × 16 ÷ 8 = 32 000 字节
- 每分钟约 **1.9 MB**，一小时约 **115 MB**
- CD 音乐：一分钟约 10.6 MB

::: notes
CD：44 100 × 16 ÷ 8 × 2 = 176 400 字节每秒。MP3 等格式压缩后只有它的十分之一左右。
:::

## 波形与频谱：声音的“指纹”
!sim sound-spectrum
- 白光经过三棱镜分成七色，声音也能分解成不同频率
- 音叉：频谱只有一根线
- “啊”“衣”：嘴型不同，**共振峰**位置不同
- 噪音：频谱像一片平地

::: notes
对应体验 7-1。请学生对比 a、i、u 三个元音的频谱，计算机正是靠共振峰的位置来分辨元音。再把采样率调低，听声音怎样变闷。
:::

# 7.2 语音识别

## 语音识别的大致流程
!mermaid 1
- **预处理**：去噪、端点检测
- **特征提取**：每帧 25 毫秒，每秒 100 帧
- **声学模型**：这一段最像哪个音
- **语言模型**：“期中考试”还是“期终考试”

::: notes
语音识别（ASR）把声音变成文字。同一串音可能对应很多不同的字，语言模型根据上下文选最合理的那个，和第 5 章的语言模型是同一个思路。
:::

## 算一算：会议录音的字错率
- 原话：今天下午三点在三楼会议室开会（14 字）
- 识别：今天下午点在三楼会议是开会了
- 删除 1、替换 1、插入 1
- 字错率 = 3 ÷ 14 ≈ **21%**
- 时间、数字、人名一定要人工核对

::: notes
字错率越低越准。字错率只看错了几个字，不看错得严不严重：“三点”漏了“三”，意思就完全不对了。实际评价用几千句测试录音一起算。
:::

## 语音识别的难点
| 难点 | 例子 | 改进办法 |
|---|---|---|
| 噪声 | 马路边、几个人同时说 | 麦克风阵列、带噪声训练 |
| 方言和口音 | 粤语、四川话 | 方言数据训练专门模型 |
| 同音字和专业词 | 期中 / 期终，公司名、药名 | 语言模型、自定义词表 |

::: notes
教材 7.2.4 节还列了说话不规范（口头禅、改口）、远距离和回声等难点。
:::

## 语音唤醒
- “小度小度”“天猫精灵”：一听就亮
- 设备一直在“听”，唤醒模型很小，在**本地**运行
- 听到唤醒词才开始联网识别
- 唤醒前的声音不上传，保护隐私

::: notes
唤醒模型只负责认出唤醒词；听到唤醒词后，才把后面的话交给云端做完整的语音识别。
:::

# 7.3 语音合成

## 从文字到声音
| 阶段 | 怎么做 | 听起来 |
|---|---|---|
| 拼接合成 | 挑录好的字词拼起来 | 衔接生硬，“机器腔” |
| 参数合成 | 统计模型算出声音参数 | 流畅，但发闷 |
| 神经网络合成 | 深度学习直接生成波形 | 自然，有感情 |

::: notes
语音合成（TTS）把文字变成声音，导航播报、有声书、读屏软件都用它。
:::

## 语音合成的大致流程
!mermaid 2
- **文本分析**：多音字、数字怎样读
- **韵律预测**：哪里停顿、哪个字重读
- **声学模型**：生成频谱
- **声码器**：还原成声音波形

::: notes
多音字：“银行”的“行”读 háng，“行走”的“行”读 xíng。数字：“2025 年”读“二零二五年”，“2025 元”读“两千零二十五元”，电话号码里的“110”读“幺幺零”。停顿：“我们 / 去公园”和“我们去 / 公园”意思不同。对应体验 7-2 第二部分。
:::

# 7.4 声纹识别与语音克隆

## 声纹识别
- 每个人的声带、口腔不同，声音有独特的**声纹**
- 和人脸识别一样：变成一串数字，比相似度
- 不用接触，打电话就能用
- 受感冒、情绪、设备、噪声影响，重要场合要配合其他验证

::: notes
1 比 1 验证“你是不是你”，1 比 N 辨认“你是谁”。
:::

## 语音克隆：几秒钟就能“偷走”一个人的声音
- 以前要录几个小时
- 2023 年：**3 秒**录音就能模仿陌生人的声音
- 正当用途：为失声的人保留声音、影视配音
- 被滥用：冒充亲友诈骗

::: notes
微软 VALL-E 模型的研究。今天很多开源工具和商业产品都能用几秒到几十秒的录音克隆出逼真的声音。
:::

## 防范 AI 拟声诈骗
- 骗子录下“喂，你好，哪位？”就够了
- 编造车祸、生病，要求马上转账、别告诉家人
- **挂断后用自己保存的号码回拨**
- 和家人约定**暗号**
- 不随意公开大段语音；可疑情况拨打 **96110**

::: notes
陌生电话少说话，不要被引导说出“是”“对”等词。被骗后立即报警。课后请学生把这几条讲给家里的老人听。
:::

## 声音受法律保护
- 《民法典》：声音保护参照**肖像权**
- 未经同意，不得模仿、使用他人的声音营利或毁誉
- 《深度合成管理规定》（2023 年 1 月 10 日施行）：编辑他人人声要取得**单独同意**
- 2024 年北京互联网法院：声音权益**及于 AI 声音**，判赔 25 万元

::: notes
即使是为了好玩，也不要随意用别人的声音“克隆”去发视频、做配音，更不能冒充别人说话。
:::

# 7.5 语音交互与语音大模型

## 一问一答的语音助手
!mermaid 3
- 识别 → 理解 → 回答 → 合成
- 每一步都花时间，加起来一两秒
- 变成文字后，语气和情绪丢了

::: notes
传统流水线的问题：慢、不能打断、听不出情绪。
:::

## 能实时对话的语音大模型
- 声音也切成 Token，一个大模型统一处理
- **反应快**：GPT-4o 平均约 320 毫秒
- **能被打断**、**听得出情绪**
- 和第 5、6 章是同一个思路

::: notes
2024 年 5 月 OpenAI 发布 GPT-4o，响应速度接近人与人交谈时的反应速度。
:::
