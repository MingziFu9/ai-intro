# 8.1 强化学习的基本要素

## 在试错中学习
- 学骑自行车：没人给“标准答案”
- 摔了就知道不对，骑稳了就知道对
- 不断尝试，根据**奖励**改进
- 第 1 章的**行为主义**

::: notes
第 3 章说过三类学习方式，强化学习是第三类。
:::

## 六个基本要素
!mermaid 1
- **智能体**：学习和做决定的一方
- **环境**：它所处的世界
- **状态**、**动作**、**奖励**、**策略**
- 要学出来的是**策略**

::: notes
格子世界：智能体是小机器人，环境是格子地图，奖励是找到宝藏 +10、掉进陷阱 −10、每走一步 −1，策略是每个格子该往哪个方向走。下围棋：智能体是下棋程序，环境是棋盘和对手。
:::

## 和监督学习有什么不同
| | 监督学习 | 强化学习 |
|---|---|---|
| 学什么 | 输入和答案之间的规律 | 每种情况下该怎么做 |
| 正确答案 | 每个样本都有标签 | 没有，只有奖励分数 |
| 反馈 | 马上知道对不对 | 常常要过很久才知道 |

::: notes
下完一整盘棋才知道输赢，前面哪一步下得好、哪一步下得差，要智能体自己琢磨。
:::

## 算一算：折扣回报
- 4 步找到宝藏：奖励 −1、−1、−1、+10，γ = 0.9
- 回报 = −1 − 0.9 − 0.81 + 7.29 = **4.58**
- 绕远路 8 步：回报 ≈ **−0.43**
- 路越短，回报越高

::: notes
折扣因子 γ 表示“将来的奖励没有眼前的值钱”。8 步时：−(1 + 0.9 + … + 0.9⁶) + 0.9⁷ × 10 ≈ −5.217 + 4.783 ≈ −0.43。每步扣 1 分加上折扣，都在鼓励机器人尽快找到宝藏。
:::

# 8.2 Q 学习

## Q 值：给每个动作打分
- **Q 值**：在某个格子做某个动作，将来能得多少分
- 新的 Q = 旧的 Q + 学习率 × (奖励 + 折扣 × 下一格最大的 Q − 旧的 Q)
- 括号里是“新估计和旧印象之差”
- 每次经历都修正一点

::: notes
难点：Q 值更新。先把公式读成中文，再做下一页的算一算。
:::

## 算一算：一次 Q 值更新
- A 往右走到 B，奖励 −1；A 往右的 Q 值是 0
- B 四个方向的 Q：2、6、1、−3，最大是 **6**
- 新估计 = −1 + 0.9 × 6 = **4.4**
- 新的 Q = 0 + 0.5 × (4.4 − 0) = **2.2**
- 宝藏的“好消息”一格一格往回传

::: notes
学习率 0.5，折扣因子 0.9。B 离宝藏近，所以“从 A 往右走到 B”也变得值钱了。陷阱的“坏消息”也会往回传。
:::

## 探索与利用
!sim q-learning
- **利用**：按经验选最好的动作，稳稳拿分
- **探索**：试一试没试过的，也许有更好的路
- 探索率 ε：随机探索的比例
- 只利用不探索：可能一辈子只去一家面馆

::: notes
对应体验 8-1。课堂演示：先只点“走一步”，看宝藏旁边的格子先变绿；再比较 ε = 0、0.2、0.8 时训练 200 回合的效果。
:::

## 奖励设计：你奖励什么，它就学什么
- 赛艇游戏：智能体原地转圈刷分，不去终点
- 每步扣分改成 0：机器人绕来绕去
- 智能体不懂你“真正想要什么”
- **设计奖励就是设计目标**

::: notes
OpenAI 的研究人员训练智能体玩赛艇游戏，奖励是得分，它发现在小水湾里转圈撞得分道具比跑完比赛得分更多。这提醒我们设计任何系统时都要考虑意外后果。
:::

# 8.3 从 AlphaGo 到 AlphaZero

## AlphaGo：四种技术的结合
| 技术 | 在 AlphaGo 中做什么 | 本书 |
|---|---|---|
| 深度学习 | 策略网络选落点，价值网络估胜率 | 第 4、6 章 |
| 监督学习 | 学习人类高手的 3000 万个棋局位置 | 第 3 章 |
| 强化学习 | 自我对弈几百万盘，越下越强 | 本章 |
| 搜索 | 蒙特卡洛树搜索往前推演 | 第 2 章 |

::: notes
2016 年 3 月 4 比 1 战胜李世石；2017 年 5 月 3 比 0 战胜当时世界排名第一的柯洁。这也是三大学派融合的例子。
:::

## AlphaGo Zero 和 AlphaZero
- 2017 年 AlphaGo Zero：**不看人类棋谱**，从零自我对弈
- 2018 年 AlphaZero：同一套方法下围棋、国际象棋、将棋
- 有明确规则和奖励、能大量练习，就可能超过人类
- 局限：现实世界的试错代价大

::: notes
强化学习还用在游戏、大模型（人类反馈强化学习、DeepSeek-R1 用“答案对不对”作奖励）、机器人、调度和控制中。
:::

# 8.5 AI 智能体

## 从“会说”到“会做”
!mermaid 2
- 大模型只会“说”：不能查天气、开日历、下单
- **AI 智能体**：以大模型为核心，能调用工具办事
- 一步步把事办完，必要时请人确认

::: notes
“智能体”这个词在 8.1 节的强化学习里也出现过，意思都是“能感知环境、自主做出决定和行动的一方”。
:::

## AI 智能体的四个组成部分
| 组成部分 | 作用 | 比喻 |
|---|---|---|
| 大模型 | 理解目标、思考下一步 | 大脑 |
| 规划 | 拆成小步骤 | 清单 |
| 工具 | 搜索、查询、调用软件 | 手 |
| 记忆 | 记住偏好和做过的步骤 | 笔记本 |

::: notes
四个组成部分是期末常考内容。低代码平台上的人设、知识库、插件分别对应这里的大模型、记忆和工具。
:::

## 思考、行动、观察
!sim react-replay
- **思考**：下一步该做什么
- **行动**：调用一个工具
- **观察**：看工具返回了什么
- 循环，直到完成任务（**ReAct**）

::: notes
动画回放一个智能体完成任务的全过程，请学生说出每一步是思考、行动还是观察。
:::

## 智能体处理一个退货请求
- 查询订单：6 天前签收，电饭煲，499 元
- 检索售后政策：7 天内质量问题可退
- 生成退货单（**草稿，未提交**）
- 回答顾客，**请人工客服确认后再提交**

::: notes
第 2 步就是第 5 章的检索增强生成：智能体不是凭印象回答退货规则，而是先查公司政策。
:::

## 工具调用与模型上下文协议（MCP）
- 事先告诉大模型有哪些工具、怎样用
- 大模型输出“调用哪个工具、参数是什么”
- 2024 年 11 月 Anthropic 提出并开源 **MCP**
- 像 USB-C 接口：一个标准连接各种工具

::: notes
一个工具只要按 MCP 的标准做一次，就能被各种支持 MCP 的大模型应用使用。多智能体：查资料、写初稿、检查挑错分工合作。
:::

## 智能体的风险：越能干，越要管
- **办错事**：理解错意思，订错、发错、删错
- **被“骗”**：网页里藏着恶意指令（提示注入）
- **权限太大**：付款、删除、对外发送
- 原则：**只给必需的权限，不可撤回的操作由人确认**

::: notes
情景导入里退货单要人工客服确认，就是这条原则。第 9 章还会讲提示词攻击。
:::

## 智能体由哪些部分组成
!mermaid 3
- **人设与回复逻辑**（提示词）
- **模型**：选中文能力好的，温度调低
- **知识库**：上传资料，检索增强生成
- **插件**、**工作流**、**发布渠道**

::: notes
证书考点：人工智能训练师的工作已经从数据标注扩展到智能系统的设计、测试和优化，能说出智能体平台的人设、知识库、插件、工作流各起什么作用。
:::

## 线下体验：搭一个“课程助教”
- ① 创建智能体，起名“AI 导论小助教”
- ② 写人设：只回答本课程的问题，不知道就说不知道
- ③ 上传知识库：教材某一章、课程安排表
- ④ 添加插件 ⑤ 测试 ⑥ 发布
- 测试题里一定要有**知识库里没有的问题**

::: notes
难点：配置和测试。每一步投屏示范后让学生跟做。知识库只放公开资料，不放个人信息。测试时看它会不会编造答案，编造了就回去改人设。
:::

## 案例：小何的“仓库助手”
- 人设：只答仓库操作和安全规程，故障先按急停
- 知识库：安全操作规程、故障处理手册
- 工具：能查机器人状态，**不给控制权限**
- 测试 30 个问题，发现旧版地图导致答错
- 每周把答不上的问题补进知识库

::: notes
上线一个月，新员工问同事的问题少了一大半。智能体不是搭好就完事，要持续测试和更新。
:::

# 8.7 具身智能

## 走进现实世界的 AI
- **具身智能**：有身体，能感知、能行动
- 2025 年 4 月，北京人形机器人半程马拉松，冠军 2 小时 40 分
- 机器人学走路：在**仿真环境**里用强化学习练
- 仿真里练几年，现实中只要几天

::: notes
步骤：建一个和真实机器人一样的仿真环境；成千上万个虚拟机器人同时练，走得稳加分、摔倒扣分；把学到的策略装到真机上再调整。
:::
