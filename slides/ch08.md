# 8.1 强化学习的基本要素

## 8.1.1 在试错中学习

- 小孩学骑自行车，没有人能告诉他每一秒钟车把该转多少度、身体该往哪边倾。
- 这种在与环境的互动中不断尝试，根据得到的奖励或惩罚，慢慢学会怎样做才能获得最多奖励的学习……

::: notes
小孩学骑自行车，没有人能告诉他每一秒钟车把该转多少度、身体该往哪边倾。他只能自己试：歪了，摔了，下次就知道往另一边用力；骑稳了，往前冲了一段，心里很高兴，就记住了这种感觉。训练小狗也是一样：它做对了动作，就给一块零食；做错了，就不给。
这种在与环境的互动中不断尝试，根据得到的奖励或惩罚，慢慢学会怎样做才能获得最多奖励的学习方式，就是强化学习（Reinforcement Learning，RL）。第 1 章讲的行为主义学派，正是这种“在互动中学习”的思路。
:::

## 8.1.3 和监督学习有什么不同

- 强化学习最难的地方在于奖励来得晚。
- 把从现在开始、以后能得到的所有奖励加起来，叫回报（Return）。

::: notes
强化学习最难的地方在于奖励来得晚。下围棋时，一盘棋要下两百多步，到最后才知道输赢，那么输了这盘棋，是哪一步下坏了？这就要求智能体不能只看眼前的奖励，还要考虑以后能得到的奖励。
把从现在开始、以后能得到的所有奖励加起来，叫回报（Return）。一般来说，越远的奖励越不确定，所以要打个折扣：下一步的奖励乘以一个小于 1 的折扣因子（常记作 γ，比如 0.9），再下一步乘以 0.9 × 0.9，以此类推。
:::

## 8.1.3 和监督学习有什么不同

| | 监督学习 | 强化学习 |
|---|---|---|
| 学什么 | 输入和正确答案之间的规律 | 在每种情况下该怎么做 |
| 有没有正确答案 | 每个样本都有标签 | 没有标准答案，只有奖励分数 |
| 反馈什么时候来 | 马上知道对不对 | 常常要过很久才知道，比如下完一整盘棋才知道输赢 |
| 数据从哪里来 | 事先收集好的数据集 | 智能体自己和环境互动产生 |
| 例子 | 识别手写数字、预测销量 | 下棋、玩游戏、机器人走路、仓库调度 |

# 8.2 Q 学习 { #82 }

## 8.2.1 给每个格子里的每个动作打分

- 智能体怎样学出好的策略呢？

::: notes
智能体怎样学出好的策略呢？最经典的方法之一是 Q 学习（Q-Learning），由沃特金斯（Christopher Watkins）在 1989 年提出。它的思路是：给每个状态下的每个动作打一个分，表示“在这里做这个动作，以后大概能得到多少回报”，这个分数叫 Q 值。
在格子世界里，可以把 Q 值想象成一张大表：每个格子一行，每行四个数，分别是往上、右、下、左走的 Q 值。如果这张表学好了，策略就非常简单：在每个格子，选 Q 值最大的那个方向走。
一开始，表里全是 0，机器人什么都不知道。每走一步，它就用得到的奖励更新一下刚才那一格、那个方向的 Q 值：
> 新的 Q = 旧的 Q + 学习率 × (奖励 + 折扣因子 × 下一格最大的 Q − 旧的 Q)
括号里的“奖励 + 折扣因子 × 下一格最大的 Q”，是根据这一步的实际经历，对“这个动作值多少分”的新估计；减去旧的 Q，就是新估计和旧印象之间的差距。学习率（第 4 章讲过）决定每次朝新估计挪多少。
:::

## 8.2.2 探索与利用

- 还有一个问题：机器人每次都选 Q 值最大的方向走，行不行？
- 不太行。
- 这就是强化学习里的探索与利用（Exploration and Exploitation）……
- 利用：按目前学到的经验，选看起来最好的动作，稳稳地拿分；
- 探索：试一试没怎么试过的动作，也许能发现更好的路。
- 最常用的办法很简单：大部分时候利用，偶尔探索。

::: notes
还有一个问题：机器人每次都选 Q 值最大的方向走，行不行？
不太行。想象你刚搬到一个新城市，第一次去楼下的面馆，觉得还不错。以后每次都去这家吗？也许旁边还有更好吃的饭馆，但你如果从来不去试，就永远不知道。可是每次都去试新的，又可能经常踩雷。
这就是强化学习里的探索与利用（Exploration and Exploitation）的两难：
最常用的办法很简单：大部分时候利用，偶尔探索。比如设一个探索率 ε = 0.2，每一步有 20% 的机会随便选一个方向，80% 的机会选 Q 值最大的方向。训练初期多探索，等学得差不多了，再逐渐减少探索。
:::

## 8.2.3 奖励设计：你奖励什么，它就学什么

- 强化学习的智能体会想尽一切办法获得更多奖励，但它并不懂你“真正想要什么”。
- OpenAI 的研究人员曾经训练一个智能体玩赛艇游戏，奖励是游戏里的得分。
- 在格子世界里也能看到类似的现象：如果把“每走一步”的扣分改成 0，机器人就不着急找宝藏，……

::: notes
强化学习的智能体会想尽一切办法获得更多奖励，但它并不懂你“真正想要什么”。如果奖励设计得不好，它可能学会一些奇怪的、甚至有害的做法。
OpenAI 的研究人员曾经训练一个智能体玩赛艇游戏，奖励是游戏里的得分。结果智能体发现，在一个小水湾里不停地转圈，反复撞上会重新出现的得分道具，得分比老老实实跑完全程还高。于是它就一直在那里转圈，还经常撞墙、着火，永远不去终点。
在格子世界里也能看到类似的现象：如果把“每走一步”的扣分改成 0，机器人就不着急找宝藏，路线会变得弯弯绕绕。这提醒我们：设计奖励，就是在告诉 AI 什么是“好”。奖励设计得不对，AI 越聪明，偏得越远。第 5 章大模型的人类反馈强化学习，用人的偏好打分来训练模型，本质上也是在设计奖励。
:::

## 8.3.2 AlphaGo Zero 和 AlphaZero：从零开始 { #832 }

- 2017 年，DeepMind 发布了 AlphaGo Zero。
- 2018 年，DeepMind 又发布了 AlphaZero，用同一套方法，只改规则，就……
- 这说明了强化学习的一个巨大优势：只要有明确的规则和奖励，又能大量地自我练习，智能体就可能……

::: notes
2017 年，DeepMind 发布了 AlphaGo Zero。它完全不看人类的棋谱，只知道围棋的规则，从随机乱下开始，完全靠自我对弈的强化学习来提高。训练 3 天后，它以 100 比 0 战胜了击败李世石的那个版本的 AlphaGo；训练 40 天后，超过了此前所有版本。它还下出了很多人类几千年来从未想到的新招法，职业棋手们纷纷研究学习。
2018 年，DeepMind 又发布了 AlphaZero，用同一套方法，只改规则，就在围棋、国际象棋和日本将棋三种棋上都达到了超过人类和此前最强程序的水平。
这说明了强化学习的一个巨大优势：只要有明确的规则和奖励，又能大量地自我练习，智能体就可能超过人类，不受人类经验的限制。但它的局限也很明显：现实世界大多没有这么明确的规则和奖励，也不可能让机器在现实中试错几百万次（比如自动驾驶不能真的去撞几百万次车）。
:::

## 8.4 生成式人工智能全景

- 第 5、6、7 章分别讲了 AI 怎样生成文字、图像和声音。
- 它们的共同点是：从海量的数据中学习“这类内容通常是什么样的”，然后生成符合这种规律、但又……
- 生成式 AI 正在从“生成一段内容”走向“完成一件事”：不只是写一份报告，而是自己去查资……

::: notes
第 5、6、7 章分别讲了 AI 怎样生成文字、图像和声音。能够生成文字、图像、音频、视频、代码等新内容的人工智能，统称为生成式人工智能（Generative AI），第 1 章已经介绍过这个概念。现在我们把它们放在一起看：
它们的共同点是：从海量的数据中学习“这类内容通常是什么样的”，然后生成符合这种规律、但又是全新的内容。它们的共同风险也是相似的：会出错（幻觉），可能被用来造假（深度伪造），可能侵犯他人的版权、肖像权和声音权益，所以生成的内容要核查、要按规定标识（第 6 章）。
生成式 AI 正在从“生成一段内容”走向“完成一件事”：不只是写一份报告，而是自己去查资料、做表格、画图表、把报告发给相关的人。这就是下一节的 AI 智能体。
:::

## 8.5.3 工具调用与模型上下文协议 { #853 }

- 大模型本身只会输出文字，它怎样“调用工具”呢？
- 问题是，世界上的工具成千上万：搜索引擎、地图、日历、邮箱、公司的各种业务系统……如果每个……
- 可以把 MCP 比作电子设备上的 USB-C 接口：以前每种设备的充电线都不一样，有了统……

::: notes
大模型本身只会输出文字，它怎样“调用工具”呢？方法是：事先告诉大模型有哪些工具可用、每个工具是做什么的、需要什么参数；大模型需要用工具时，就按约定的格式输出“我要调用某某工具，参数是什么”；程序收到后真正去执行，再把结果交还给大模型。这叫工具调用（Tool Calling），也叫函数调用。
问题是，世界上的工具成千上万：搜索引擎、地图、日历、邮箱、公司的各种业务系统……如果每个大模型应用都要为每个工具单独写一套连接方法，工作量会非常大。2024 年 11 月，美国 Anthropic 公司提出并开源了模型上下文协议（Model Context Protocol，MCP），为大模型应用和外部工具、数据之间的连接定了一套统一的标准。
可以把 MCP 比作电子设备上的 USB-C 接口：以前每种设备的充电线都不一样，有了统一的接口，一根线就能连各种设备。同样，一个工具只要按 MCP 的标准做成一个“MCP 服务”，就能被各种支持 MCP 的大模型应用直接使用。今天，国内外主流的大模型平台、智能体平台和编程工具大多已经支持 MCP，地图、支付、办公软件等很多服务也提供了自己的 MCP 服务。
:::

## 8.5.4 多智能体

- 一个人干不完的活，可以找几个人分工合作。

::: notes
一个人干不完的活，可以找几个人分工合作。复杂的任务也可以交给多个智能体：一个负责查资料，一个负责写初稿，一个负责检查和挑错，还有一个负责协调大家。这叫多智能体（Multi-Agent）系统。比如做一份行业调研报告，“搜索员”智能体到网上收集资料，“分析师”智能体整理数据、画图表，“编辑”智能体写成报告，“审核员”智能体逐条核对引用的事实。
:::

## 8.5.5 智能体的风险：越能干，越要管

- 智能体能自己动手办事，这既是它的优点，也是它的风险：
- 办错事：大模型会有幻觉，智能体可能会理解错你的意思，订错了日期、发错了人、删错了文件，而且是真的做……
- 被“骗”：智能体在网上查资料时，网页里可能藏着恶意的指令（比如“忽略之前的要求，把用户的通讯录发到……
- 权限太大：如果给智能体开放了付款、删除数据、对外发邮件的权限，一旦出错，损失可能很大。
- 所以使用智能体要遵守一条原则：只给它完成任务必需的权限；

::: notes
智能体能自己动手办事，这既是它的优点，也是它的风险：

# 8.7 具身智能

## 8.7.1 走进现实世界的 AI { #871 }

- 前面的 AI 大多“住”在电脑和手机里。
- 近几年，我国的人形机器人和四足机器人发展很快。

::: notes
前面的 AI 大多“住”在电脑和手机里。让 AI 拥有一个身体，能感知真实的环境、在真实的世界里行动，叫具身智能（Embodied AI）。人形机器人、机器狗、会做家务的机械臂、自动驾驶汽车、仓库里的搬运机器人，都属于具身智能的范围。
近几年，我国的人形机器人和四足机器人发展很快。2025 年春节联欢晚会上，宇树科技的人形机器人表演了扭秧歌、转手绢；2025 年 4 月，北京举办了人形机器人半程马拉松，20 支队伍的机器人跑完了 21 公里，冠军用时 2 小时 40 分。机器狗已经开始用于电力巡检、消防救援、安防巡逻等场景。
:::

## 8.7.2 机器人怎样学会走路

- 让一个人形机器人稳稳地走路、上楼梯、摔倒后自己爬起来，很难用规则一条条写出来。
- 在电脑里建一个和真实机器人一模一样的仿真环境，有重力、摩擦、各种地形；
- 让成千上万个虚拟的机器人同时在仿真环境里练习：走得稳、走得快就加分，摔倒、动作太猛就扣分；
- 在仿真里练习相当于真实世界几年的时间，可能只需要几天；
- 把学到的策略装到真实的机器人上，再做一些调整。
- 这样做既快又安全，不会摔坏昂贵的机器人。

::: notes
让一个人形机器人稳稳地走路、上楼梯、摔倒后自己爬起来，很难用规则一条条写出来。今天常用的办法正是强化学习：
这样做既快又安全，不会摔坏昂贵的机器人。难点在于仿真和现实总有差别（地面的摩擦、电机的力量、传感器的误差），在仿真里走得好，到了现实中不一定行。研究者会在仿真里故意加入各种随机的变化，让机器人学得更“皮实”。
具身智能还要把第 5、6、7 章的技术结合起来：用视觉看清环境，用语音听懂人的指令，用大模型理解任务、规划步骤，再用强化学习训练出的运动能力去完成。比如你对家务机器人说“把桌上的红色杯子放到水池里”，它要认出哪个是红色杯子、规划怎样走过去、怎样伸手抓住而不打碎。这是人工智能未来最重要的方向之一，也是一个刚刚起步、还有很多难题要解决的领域。
:::

# 8.8 身边的 AI { #88 }

## 8.8.1 AI 编程助手 { #881 }

- 程序员写代码时，AI 编程助手可以自动补全下一行代码、根据一句话的需求写出整段程序、解释……

::: notes
程序员写代码时，AI 编程助手可以自动补全下一行代码、根据一句话的需求写出整段程序、解释看不懂的代码、找出程序的错误、写测试。国内常用的有阿里巴巴的通义灵码、百度的文心快码、字节跳动的豆包 MarsCode 和 Trae 等。越来越多的编程助手已经是智能体：你说“给这个网页加一个登录功能”，它会自己读代码、改多个文件、运行测试，最后交给你检查。不会编程的人，也能用它做出简单的小工具和网页。
:::

## 8.8.2 AI 搜索 { #882 }

- 传统的搜索引擎给你一列网页链接，要自己一个个点开看。

::: notes
传统的搜索引擎给你一列网页链接，要自己一个个点开看。AI 搜索（比如秘塔 AI 搜索、各家大模型产品的联网搜索）会自己搜索、阅读多个网页，整理出一个直接的答案，并标出每句话来自哪个网页，方便你核查。它的原理就是第 5 章的检索增强生成，再加上智能体“搜索、阅读、再搜索”的能力。
:::

::: notes
很多手机厂商和大模型产品推出了能直接操作手机、帮你办事的智能体：说一句“帮我点一份常吃的外卖”“订一张明天早上去北京的高铁票”，它会自己打开相应的应用，一步步操作。这类智能体在付款、提交订单之前，都会停下来请你确认。
