- 罗森布拉特还造出了一台感知机硬件，能学会分辨简单的图形。

::: notes
1958 年，美国心理学家罗森布拉特（Frank Rosenblatt）提出了感知机（Perceptron）。它只有一个神经元，用阶跃函数做激活函数，但它有一个了不起的地方：权重不是人设定的，而是从例子中学出来的。
感知机的学习方法很直观：拿一个例子让它判断，判对了就不动；判错了，就把权重往“能判对”的方向调一点。比如本该输出 1 却输出了 0，说明加权和太小了，那就把取值为 1 的那些输入的权重调大一点。一个个例子反复练，权重就慢慢调好了。
罗森布拉特还造出了一台感知机硬件，能学会分辨简单的图形。当时的报纸兴奋地预言，这种机器将来能走路、说话、看东西，甚至有自我意识。
:::

可是这片山地有成千上万甚至几千亿个“方向”（每个权重都是一个方向），没法画出来，也没法一眼看到最低点在哪里。我们就像一个蒙着眼睛下山的人，只能用脚感觉脚下的坡度：
这就是梯度下降（Gradient Descent）。“梯度”就是数学上的坡度，它告诉我们每个权重往哪个方向调、能让损失减小得最快。每一步怎么调，可以写成：
> 新的权重 = 旧的权重 − 学习率 × 坡度
坡度是正的（往右是上坡），就把权重调小；坡度是负的，就把权重调大。
学习率（Learning Rate）决定每一步迈多大。它是训练时最重要的设置之一：
在“两个山谷”的曲线上，你会发现：从右边出发、学习率小时，小球会停在右边那个浅一些的谷底，而不是左边更深的那个。这叫陷入局部最低点。真实的神经网络也会遇到类似的问题，不过研究发现，在参数非常多的大网络里，大多数“谷底”的好坏相差不大，所以梯度下降在实践中效果很好。
:::

## 4.3.4 训练轮次与过拟合

- 训练数据不是一次全部用完的，通常每次取一小批（比如 64 张图片）来算损失、调权重，叫一……
- 轮次多了，训练集上的损失会越来越小，但第 3 章说过，这不一定是好事：网络可能开始死记硬……

::: notes
训练数据不是一次全部用完的，通常每次取一小批（比如 64 张图片）来算损失、调权重，叫一个“批”。把训练集里所有的样本都用过一遍，叫一个训练轮次（Epoch）。一个网络往往要训练几轮到几百轮。
轮次多了，训练集上的损失会越来越小，但第 3 章说过，这不一定是好事：网络可能开始死记硬背训练数据，在测试集上反而变差，这就是过拟合。神经网络的参数很多，特别容易过拟合。常用的办法有：多收集数据、训练时随机“关掉”一部分神经元（叫随机失活，让网络不能依赖某几个神经元）、在验证集上的成绩不再提高时就停止训练（叫提前停止）。
:::

- 上面讲的网络，相邻两层的神经元两两相连，叫全连接网络。

::: notes
上面讲的网络，相邻两层的神经元两两相连，叫全连接网络。它可以处理任何数据，但对于图像和文字、声音这类有特殊结构的数据，有更合适的网络结构。本节只做概览，第 5～7 章会在具体领域里再讲。

::: notes
一张 1000 × 1000 像素的照片有 100 万个像素。如果用全连接网络，第一个隐藏层每个神经元就要连 100 万个输入，权重多得吓人，而且它不懂一个基本事实：图片里相邻的像素关系最密切，一只猫的眼睛不管出现在照片的左上角还是右下角，都是眼睛。
卷积神经网络（Convolutional Neural Network，CNN）专门为图像设计。它的核心是一个个小“窗口”（比如 3 × 3 个像素），叫卷积核。卷积核在图片上从左到右、从上到下地滑动，每到一个位置，就把窗口里的像素加权求和，看这一小块像不像它要找的图案。同一个卷积核在整张图上共用一组权重，所以不管猫眼睛出现在哪里，都能被找到，权重也少得多。

## 4.4.2 循环神经网络：带着记忆往下读

- 文字、语音、股价这类数据有一个共同点：它们是序列，有先后顺序，前面的内容会影响后面的意思。
- 循环神经网络（Recurrent Neural Network，RNN）像人读书一样，一……
- 普通的循环神经网络记性不好，句子一长，前面的内容就忘了。

::: notes
文字、语音、股价这类数据有一个共同点：它们是序列，有先后顺序，前面的内容会影响后面的意思。“我不喜欢这部电影”和“我喜欢这部电影，不是吗”，关键在于词的顺序。
循环神经网络（Recurrent Neural Network，RNN）像人读书一样，一个词一个词地往下读，每读一个词，就把“到目前为止读到的意思”记在一个“记忆”（叫隐藏状态）里，带着它去读下一个词。读完整句话，记忆里就有了整句的意思。
普通的循环神经网络记性不好，句子一长，前面的内容就忘了。1997 年提出的长短期记忆网络（LSTM）加了几道“门”，决定哪些该记住、哪些该忘掉，记性好了很多，曾广泛用于机器翻译、语音识别和输入法。2017 年以后，在处理文字上，循环神经网络逐渐被能同时看整句话的 Transformer 取代（第 5 章），但它“带着记忆读序列”的思路仍然很有启发性。
:::

## 4.4.2 循环神经网络：带着记忆往下读

| | 全连接网络 | 卷积神经网络（CNN） | 循环神经网络（RNN） |
|---|---|---|---|
| 怎样看数据 | 一次看全部，每个输入都连 | 用小窗口一块块地看 | 按顺序一个个地看，带着记忆 |
| 擅长的数据 | 表格数据、简单任务 | 图像、视频 | 文字、语音、时间序列 |
| 典型应用 | 体验 4-2 的小网络 | 人脸识别、医学影像、工业质检 | 早期的机器翻译、语音识别、输入法 |

# 4.5 深度学习为什么爆发

## 4.5 深度学习为什么爆发

- 神经网络的想法在 1940～1950 年代就有了，反向传播在 1986 年就流行开来，为……

::: notes
神经网络的想法在 1940～1950 年代就有了，反向传播在 1986 年就流行开来，为什么直到 2012 年以后才迎来大爆发？答案就是第 1 章说的三要素在这个时候同时成熟了。
:::

## 4.5.1 数据：有了足够多的“练习题”

- 深度神经网络参数多，需要大量数据才能训练好，否则很容易过拟合。

::: notes
深度神经网络参数多，需要大量数据才能训练好，否则很容易过拟合。2009 年，美国普林斯顿大学的李飞飞团队发布了 ImageNet 图像数据集，最终收录了 1400 多万张人工标注的图片，涵盖两万多个类别。从 2010 年起，基于它举办的图像识别比赛使用其中约 120 万张训练图片、1000 个类别。这是此前任何数据集都无法相比的规模。与此同时，互联网和智能手机让照片、语音、文字的数量急剧增长，深度学习有了足够的“练习题”。
:::

## 4.5.2 算力：GPU 让训练快了几十倍 { #452 }

- 训练神经网络，主要就是做大量的乘法和加法。

::: notes
训练神经网络，主要就是做大量的乘法和加法。CPU 像几位能力很强的教授，什么题都会做，但人少；GPU 原本是为电脑游戏画图设计的，像几千名小学生，每人只会做简单的算术，但可以同时做。神经网络的计算恰好是“大量简单算术”，交给 GPU 快得多。2012 年的 AlexNet 就是在两块游戏显卡上训练了五六天完成的，如果用当时的 CPU，可能要几个月。
:::

## 4.5.3 算法：一系列关键改进

- 除了数据和算力，研究者还找到了一系列让深层网络更好训练的方法：
- 用 ReLU 代替 Sigmoid 做激活函数，解决了层数多时坡度在反向传播中越来越小、前面的层几……
- 随机失活（Dropout）等方法，减轻了过拟合；
- 2015 年提出的残差网络（ResNet），在层与层之间加“捷径”，让 152 层的网络也能训练好；
- 更好的权重初始化方法、更聪明的梯度下降变体（如 Adam），让训练更快更稳定。

# 4.6 深度学习框架与算力

## 4.6.1 深度学习框架：搭神经网络的“积木”

- 自己从零写代码来实现神经网络的前向计算、反向传播和梯度下降，非常麻烦，也容易出错。
- 国产框架的意义不只是“多一个选择”。

::: notes
自己从零写代码来实现神经网络的前向计算、反向传播和梯度下降，非常麻烦，也容易出错。深度学习框架（Deep Learning Framework）把这些常用的功能都做好了：搭网络像搭积木一样，选好层的类型和数量；反向传播自动完成，不用自己算坡度；还能自动调用 GPU 加速。今天几乎所有的深度学习项目都是在框架上完成的。
国产框架的意义不只是“多一个选择”。在关键技术上实现自主可控，是我国人工智能发展战略的一部分。飞桨提供了大量面向产业的现成模型，比如文字识别 PaddleOCR、目标检测 PaddleDetection，很多企业直接拿来用；昇思则和国产昇腾芯片一起，构成了一整套国产的 AI 软硬件体系。框架的安装、使用和模型训练，在《人工智能开发框架技术》中详细学习。
:::

## 4.6.1 深度学习框架：搭神经网络的“积木”

| 框架 | 开发者 | 开源时间 | 特点 |
|---|---|---|---|
| TensorFlow | 谷歌 | 2015 年 | 最早流行的框架之一，部署工具丰富，常配合更简洁的 Keras 接口使用 |

# 4.7 身边的 AI { #47 }

## 4.7.1 刷脸解锁

- 拿起手机，看一眼就解锁了。

::: notes
拿起手机，看一眼就解锁了。手机前置的摄像头（有的还有专门的红外和深度传感器）拍下你的脸，一个卷积神经网络把它变成一串数字（相当于“人脸特征”），再和你录入时保存的那串数字比较，足够接近就解锁。整个过程在手机的 NPU 上完成，不到一秒，你的人脸数据也不用上传到网上（第 6 章）。
:::

## 本章小结

- 人工神经元模仿生物神经元：把输入乘以权重后求和，加上偏置，再经过激活函数得到输出。
- 感知机是会从例子中学习权重的单个神经元，但只能学会用一条直线分开的问题，学不会“异或”。
- 隐藏层很多的神经网络叫深度神经网络，用它从数据中学习就是深度学习。
- 训练就是不断调整权重和偏置：用损失函数衡量错得有多厉害，用反向传播把误差一层层往回分摊、算出每个权重的坡度，用梯度下降……
- 卷积神经网络用小窗口在图上滑动，逐层提取边缘、纹理、部件、物体等特征，擅长图像；
- 深度学习在 2012 年后爆发，是因为数据（ImageNet）、算力（GPU）、算法（ReLU、残差网络等）同时成熟。
- 深度学习框架有 TensorFlow、PyTorch 和国产的飞桨、昇思；
