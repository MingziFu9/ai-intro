# 6.1 图像在计算机里是什么

## 6.1 图像在计算机里是什么

- 计算机视觉（Computer Vision，CV）研究的是怎样让计算机“看懂”图像和视频……

::: notes
计算机视觉（Computer Vision，CV）研究的是怎样让计算机“看懂”图像和视频：认出里面有什么、在哪里、在发生什么。人看一眼照片就能说出“一只猫趴在沙发上”，可是对计算机来说，一张照片只是一大堆数字。
:::

## 6.1.1 像素与分辨率

- 把一张数码照片不断放大，最后会看到一个个小方格，每个小方格只有一种颜色。
- 分辨率越高，图片越清楚，但数据量也越大。

::: notes
把一张数码照片不断放大，最后会看到一个个小方格，每个小方格只有一种颜色。这些小方格叫像素（Pixel），是数字图像的最小单位。一张图片横着有多少个像素、竖着有多少个像素，叫它的分辨率（Resolution），通常写成“宽 × 高”。
分辨率越高，图片越清楚，但数据量也越大。识别模型通常会先把图片缩小到固定的尺寸再处理，既省算力，又能让不同大小的图片统一起来。
:::

## 6.1.2 灰度与 RGB 颜色 { #612 }

- 黑白照片里，每个像素用一个数表示亮度，叫灰度值，通常从 0 到 255：0 是纯黑，25……
- 彩色照片里，每个像素用三个数表示，分别是红（R）、绿（G）、蓝（B）三种颜色的强度，每个……
- 所以一张彩色照片，在计算机里是三张同样大小的数字表格叠在一起，分别叫红、绿、蓝三个通道。

::: notes
黑白照片里，每个像素用一个数表示亮度，叫灰度值，通常从 0 到 255：0 是纯黑，255 是纯白，中间是各种深浅的灰。所以一张 32 × 32 的灰度图，在计算机里就是一张 32 行、32 列的数字表格。
彩色照片里，每个像素用三个数表示，分别是红（R）、绿（G）、蓝（B）三种颜色的强度，每个数也是 0～255，这叫 RGB 颜色。三种光按不同强度混合，就能调出各种颜色：
所以一张彩色照片，在计算机里是三张同样大小的数字表格叠在一起，分别叫红、绿、蓝三个通道。很多处理会先把彩色图转成灰度图，常用的公式是：灰度 ≈ 0.299 × R + 0.587 × G + 0.114 × B。绿色的系数最大，因为人眼对绿色最敏感。
:::

## 6.1.3 计算机“看”图难在哪里

- 既然图片就是一堆数字，计算机为什么不能直接认出猫呢？
- 角度不同：猫的正脸、侧脸、背影，像素完全不同；
- 光线不同：白天和晚上、阳光下和阴影里，同一只猫的像素值相差很大；
- 大小和位置不同：猫可能占满整张照片，也可能只是角落里的一小块；
- 遮挡：猫可能藏在沙发后面，只露出半个头；
- 同类差异大：橘猫、黑猫、长毛猫、短毛猫，长得各不相同；

## 6.2.3 卷积神经网络：卷积核是学出来的

- 上面这些卷积核里的数是人设计的。
- 一个卷积神经网络由很多层组成，每一层都有几十到几百个卷积核：
- 卷积层：用很多个卷积核分别扫过图片，每个卷积核找一种图案，得到一张“特征图”；
- 池化层：把特征图缩小，保留最重要的信息。
- 卷积层和池化层交替叠很多层，最后用全连接层输出“这张图是猫”的概率。
- 层数越深，每个位置“看到”的原图范围越大，学到的特征也越复杂。

## 6.2.4 ImageNet 比赛：深度学习的转折点 { #624 }

- 第 4 章提到过 ImageNet 数据集。
- 短短三四年，错误率从 26% 降到 3.6%。

::: notes
第 4 章提到过 ImageNet 数据集。2010 年到 2017 年，每年都有一场基于它的图像识别比赛：给 1000 个类别、约 120 万张训练图片，看谁的模型在测试图片上认得最准。比赛用的指标是“前 5 错误率”：模型给出 5 个最可能的答案，正确答案不在其中就算错。
短短三四年，错误率从 26% 降到 3.6%。从此，计算机视觉几乎全面转向了深度学习。今天，图像分类已经是比较成熟的技术，研究的重点转向了更难的任务和更广的应用。
:::

- 同样是“看”，要回答的问题不同，任务也不同：
- 从左到右，回答的问题越来越细，难度也越来越大。

同样是“看”，要回答的问题不同，任务也不同：
从左到右，回答的问题越来越细，难度也越来越大。图像分类只要一个答案；目标检测要找出所有物体并框出位置；图像分割要判断每一个像素；视频分析还要加上时间，理解前后画面的变化。

| 任务 | 回答什么问题 | 输出什么 | 例子 |
|---|---|---|---|

## 6.3.2 目标检测：框得准不准

- 目标检测是应用最广的视觉任务之一。
- 怎样判断一个框“框得准不准”？

::: notes
目标检测是应用最广的视觉任务之一。2016 年提出的 YOLO（You Only Look Once，意思是“只看一眼”）方法，把整张图只送进网络一次，就同时得到所有物体的方框和类别，速度快到能实时处理视频，后来不断改进，成为工业界最常用的检测方法之一。
怎样判断一个框“框得准不准”？常用的指标是交并比（Intersection over Union，IoU）：两个框重叠部分的面积，除以两个框合起来覆盖的总面积。
:::

## 6.3.3 训练视觉模型需要标注数据

- 要训练一个目标检测模型，就要有成千上万张已经画好框、标好类别的图片。
- 标注的质量直接决定了模型的质量。
- 证书考点：人工智能训练师国家职业技能标准中，数据采集和处理、数据标注是初级和中级的核心内……

::: notes
要训练一个目标检测模型，就要有成千上万张已经画好框、标好类别的图片。这些标注工作大多由人完成：在图片上拉框、选类别，做图像分割还要沿着物体的边缘一点点描出轮廓。小吴给新缺陷画框，就是在做这件事。
标注的质量直接决定了模型的质量。框画得松松垮垮、类别标错、同一种缺陷有人标“划痕”有人标“刮伤”，模型都会学糊涂。所以标注之前要定好统一的标注规范：什么算划痕、多长的划痕要标、框要贴紧到什么程度，标完后还要抽查。
:::

# 6.4 典型应用

## 6.4.1 人脸识别

- 人脸识别是我们最熟悉的视觉应用：刷脸解锁、刷脸支付、刷脸进站、酒店入住核验。
- 第 ③ 步得到的一串数字（比如 512 个数），和第 5 章的词向量很像：同一个人不同照……
- 人脸识别有两种用法：1 比 1 是验证“你是不是你”，比如刷脸解锁、火车站把你的脸和身份……
- 人脸属于敏感的个人信息，一旦泄露无法更改，不像密码可以换一个。

!mermaid 3

::: notes
人脸识别是我们最熟悉的视觉应用：刷脸解锁、刷脸支付、刷脸进站、酒店入住核验。它一般分为四步：
第 ③ 步得到的一串数字（比如 512 个数），和第 5 章的词向量很像：同一个人不同照片的数字很接近，不同人的相差较远。第 ④ 步比的就是两串数字的相似度，超过阈值就认为是同一个人。
人脸识别有两种用法：1 比 1 是验证“你是不是你”，比如刷脸解锁、火车站把你的脸和身份证照片比对；1 比 N 是辨认“你是谁”，比如在一个几千人的公司库里找出刷脸进门的是哪位员工。1 比 N 的库越大，认错的风险越高。
人脸属于敏感的个人信息，一旦泄露无法更改，不像密码可以换一个。2025 年 6 月 1 日起施行的《人脸识别技术应用安全管理办法》 规定：使用人脸识别要告知个人并取得同意；存在其他验证方式能达到同样目的的，不得把人脸识别作为唯一的验证方式；存储的人脸信息达到 10 万人的，要向网信部门备案。所以，小区门禁、健身房如果只能刷脸进门，就不符合规定，应当同时提供刷卡、密码等方式。
:::

## 6.4.2 文字识别（OCR） { #642 }

- 文字识别（Optical Character Recognition，OCR），就是把图……
- 拍照翻译、扫描文档转 Word、发票和身份证自动录入、车牌识别、快递面单识别，用的都是文……

::: notes
文字识别（Optical Character Recognition，OCR），就是把图片里的文字变成可以编辑、可以搜索的文字。它一般分两步：先检测出图片里哪些地方有文字（目标检测），再识别每一块里写的是什么字（第 4 章的手写数字识别是它的简化版）。
拍照翻译、扫描文档转 Word、发票和身份证自动录入、车牌识别、快递面单识别，用的都是文字识别。今天的文字识别不但能认印刷体，还能认手写体、表格、公式、弯曲的文字。百度飞桨开源的 PaddleOCR 支持中文、英文等多种语言，很多企业直接拿来用。
:::

回到小吴的工厂。工业质检用相机拍下产品的照片，用图像分类或目标检测判断有没有缺陷、缺陷在哪里。和人工相比，AI 质检不知疲倦、速度快、标准统一，还能把每一个缺陷的照片和位置都记录下来，帮助工程师找出是哪道工序出了问题。
工业质检的难点在于：缺陷样本少（一天才 100 个），新的缺陷种类不断出现，而且光照、反光、产品型号变化都会影响效果。所以系统上线后，还需要像小吴这样懂生产又懂标注的人，不断补充新的样本、复核结果。
:::

## 6.4.4 医学影像

- CT、核磁共振、X 光片、眼底照片、病理切片，都是图像。
- 但医学影像的 AI 只能辅助医生，不能代替医生下诊断。

::: notes
CT、核磁共振、X 光片、眼底照片、病理切片，都是图像。AI 可以帮助医生在影像上找出可疑的结节、病灶，用图像分割勾出肿瘤的轮廓，计算大小的变化。在大量筛查的场景下，比如体检中心每天要看上千张胸部 CT，AI 可以先把可疑的挑出来，让医生重点看，减少漏诊。
但医学影像的 AI 只能辅助医生，不能代替医生下诊断。AI 给出的结果要由医生结合病人的情况综合判断，诊断的责任由医生承担。我国对辅助诊断类的 AI 软件按医疗器械管理，要经过审批才能在医院使用。
:::

# 6.5 生成图像：扩散模型

## 6.5.1 从“认图”到“画图”

- 前面讲的都是让计算机“看懂”图像。

::: notes
前面讲的都是让计算机“看懂”图像。2022 年前后，AI 学会了另一件事：根据一句话画出一幅画。输入“一只戴着草帽的橘猫坐在稻田边，夕阳，水彩画风格”，几秒钟就能得到一张从来不存在的图片。这叫文生图（Text-to-Image）。在一张已有的图片基础上修改，比如把白天的照片变成夜景、把照片变成动漫风格，叫图生图。
:::

## 6.5.2 扩散模型：从一片雪花中“洗”出图像

- 今天的文生图，主要用的是扩散模型（Diffusion Model）。
- 加噪（训练时）：拿一张真实的图片，一点一点往上加随机的“雪花点”（噪声），加几百步以后，图片就变成……
- 去噪（生成时）：训练一个神经网络，学会反过来做：给它一张带雪花的图，让它猜出“这一步加了哪些雪花”……
- 生成一张新图片时，从一片完全随机的雪花开始，让网络一步步去噪。

::: notes
今天的文生图，主要用的是扩散模型（Diffusion Model）。它的思路可以分两步理解：
生成一张新图片时，从一片完全随机的雪花开始，让网络一步步去噪。每一步去噪时都参考你写的文字，于是雪花被一点点“洗”成了符合文字描述的图片。就像雕塑家面对一块石头，一刀刀凿去多余的部分，脑子里始终想着要雕的样子。因为起点的雪花是随机的，同一句提示词每次生成的图片都不一样。
文字和图片是怎样联系起来的？2021 年 OpenAI 提出的 CLIP 模型，在 4 亿对“图片和它的文字说明”上训练，学会了把意思相同的图片和文字变成相近的向量（和第 5 章的词向量是同一个思路）。文生图模型借助这类方法“理解”文字，再用扩散模型画出来。2022 年开源的 Stable Diffusion 让普通电脑也能运行文生图，AI 绘画从此迅速普及。今天，同样的方法也被用来生成视频。
:::

# 6.6 多模态大模型

## 6.6.1 不只会读文字

- 第 5 章的大模型只处理文字。
- 今天主流的大模型产品大多已经是多模态的。
- 看图说话：描述照片里有什么，给照片写一段配文；
- 看图答题：拍一道数学题让它讲解，拍一张植物照片问它是什么花；
- 读图表和文档：上传一张统计图让它分析趋势，上传一张表格照片让它整理成电子表格；
- 找问题：拍一张电路板或者设备仪表的照片，问它有没有异常。

::: notes
第 5 章的大模型只处理文字。能同时处理文字、图片、声音、视频等多种信息的模型，叫多模态大模型（Multimodal Large Model）。“模态”就是信息的形式，文字是一种模态，图片是另一种。

## 6.6.2 多模态大模型的原理和局限

- 多模态大模型的基本做法是：用一个视觉模型把图片切成小块、变成一串向量（就像把句子切成 T……
- 多模态大模型同样会有幻觉：它可能“看到”图片里根本没有的东西，数错物体的个数，读错图表里……

::: notes
多模态大模型的基本做法是：用一个视觉模型把图片切成小块、变成一串向量（就像把句子切成 Token），再和文字的 Token 拼在一起，交给第 5 章的 Transformer 一起处理。这样，模型就能在“看”图片的同时“读”你的问题，再用文字回答。
多模态大模型同样会有幻觉：它可能“看到”图片里根本没有的东西，数错物体的个数，读错图表里的数字，把模糊的字认错。所以，和第 5 章一样，重要的信息要核查。不要上传含有身份证、银行卡、病历等敏感信息的照片。
:::
