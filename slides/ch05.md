# 5.1 让计算机读懂语言

## 中文处理的难点
- **没有空格**：先要分词
- **歧义多**：南京市长江大桥
- **一词多义**：苹果是水果还是手机
- **省略和言外之意**：“我请假了”
- **新词层出不穷**

::: notes
自然语言处理的任务有分词、文本分类、情感分析、信息抽取、机器翻译、问答、摘要、对话等。发展经历了规则方法、统计与机器学习方法、深度学习与大模型三个阶段。
:::

# 5.2 从分词到词向量

## 算一算：最大匹配法会切错吗
- 词典：研究、研究生、生命、命、起源、的
- 切分“研究生命的起源”
- 尽量切长：研究生 / 命 / 的 / 起源 ✗
- 正确：研究 / 生命 / 的 / 起源
- 统计方法比较整句话的各种切法

::: notes
最大匹配法简单快速，但只顾眼前、尽量切长，遇到歧义就会出错。今天的大模型不再按词切，而是切成 Token。
:::

## 词向量：意思相近的词距离更近
!sim word-vectors
- 把词变成一串数字（向量）
- 意思相近的词，在“词语地图”上挨得近
- 用**余弦相似度**衡量有多像

::: notes
早期用独热编码，每个词一个位置，任何两个词都“一样不像”。词向量从大量文本中学出来，“手机”和“电脑”的向量很接近。
:::

## 算一算：手机和电脑有多像
- 手机 (4, 1)，电脑 (4, 2)，香蕉 (−1, 4)
- 余弦相似度 = 对应相乘再相加 ÷ 长度乘积
- 手机和电脑：18 ÷ (4.12 × 4.47) ≈ **0.98**
- 手机和香蕉：0 ÷ … = **0**，不相关

::: notes
向量 (a, b) 的长度是 √(a² + b²)。√17 ≈ 4.12，√20 ≈ 4.47。余弦相似度越接近 1 越相似，0 表示不相关。
:::

# 5.3 语言模型与 Token

## 语言模型：预测下一个词
!mermaid 1
- 今天天气很 → 好 0.50、热 0.20、冷 0.15……
- 选一个字接上去，再预测下一个
- 一个字一个字地写出一整段话

::: notes
所有可能加起来等于 1。如果每次都选概率最大的，同样的开头每次都会写出完全相同的话，所以实际使用时通常按概率“抽签”。
:::

## Token：大模型读写的单位
- Token 可能是一个字、一个词或词的一部分
- 中文：1 个汉字约 **0.6 个 Token**
- 收费、上下文长度都按 Token 计算
- **上下文长度**：一次能“看到”多少 Token

::: notes
上下文窗口像一张办公桌：桌面能摊开的资料有限。上下文长度不等于“记性”，对话结束后模型不会记住你，有些产品的“记忆”功能是另外保存信息、下次再放进上下文。
:::

## 算一算：客服中心一天要花多少钱
- 每次输入约 1500 字，输出约 500 字，每天 1000 次
- 输入：1500 × 0.6 × 1000 = 90 万 Token → 1.8 元
- 输出：500 × 0.6 × 1000 = 30 万 Token → 2.4 元
- 合计约 **4.2 元/天**，一个月约 126 元

::: notes
价格按输入每百万 Token 2 元、输出 8 元举例，各家不同，经常调整。如果每次都把几十万字的产品手册整个发给模型，输入 Token 会多几百倍，所以要用检索增强生成只挑相关段落。
:::

## 温度：选概率最大的，还是抽签
!sim temperature-sampling
- 温度低：更确定、更保守
- 温度高：更随机、更有创意
- 写公文、算数：调低；写广告语、起名：调高

::: notes
对应体验 5-2 第一部分。请学生把温度从 0 拖到 2，各抽 20 次，数一数出现了几种不同的字。这解释了小林“同一个问题问两次回答不一样”。
:::

# 5.4 Transformer 与注意力

## 注意力：读到一个词时，该看哪些词
!sim self-attention
- “小猫追老鼠，**它**跑累了”：它 = 小猫
- “小猫追老鼠，**它**躲进了洞里”：它 = 老鼠
- 每个词都给句子里其他词打分，重点看分高的

::: notes
循环神经网络一个词一个词往下读，读到“它”时，“小猫”已经是好几个词以前的事了。注意力也解决了一词多义：“吃了一个苹果”里的苹果更多地注意“吃”。热力图颜色越深，表示关注越多。
:::

## Transformer：今天所有大模型的基础
!mermaid 2
- 2017 年谷歌提出
- 核心是**自注意力**
- 能并行计算，适合用海量数据训练

::: notes
不讲内部计算。只要知道今天的大模型几乎都基于 Transformer，第 6 章的多模态大模型也是。
:::

## 两类预训练模型：BERT 和 GPT
| | BERT | GPT |
|---|---|---|
| 怎样读 | 看完整句话 | 只看前文 |
| 训练任务 | 完形填空 | 预测下一个词 |
| 擅长 | 理解：分类、抽取 | 生成：写作、对话 |
| 提出者 | 谷歌，2018 年 | OpenAI，2018 年起 |

::: notes
GPT 的规模：2018 年 1 亿多参数，2019 年 GPT-2 15 亿，2020 年 GPT-3 1750 亿。今天的对话大模型基本都是 GPT 这一类；BERT 一类仍广泛用于搜索和检索系统。
:::

# 5.5 大模型是怎样炼成的

## 三个阶段
!mermaid 3
- **预训练**：读万卷书，学会语言和知识
- **指令微调**：学会听指令
- **人类反馈强化学习**：学会说人爱听的、该说的

::: notes
第三阶段的目的是对齐：让模型有用、诚实、无害。OpenAI 2022 年的研究发现，经过这两步的 13 亿参数模型，人们的喜爱程度超过了没经过这两步、参数多 100 多倍的 1750 亿参数模型。
:::

## 算一算：GPT-3 读了多少书
- GPT-3 训练用了约 **3000 亿个 Token**
- 3000 亿 ÷ 0.6 = 5000 亿个汉字
- 一个人每天读 2 万字，一年 730 万字
- 读完要约 **6.8 万年**

::: notes
今天的大模型，预训练数据往往是 GPT-3 的几十倍。“读得多”是大模型知识丰富的原因，也是它需要巨大算力的原因。
:::

## 推理模型与思维链
- 一步一步地想，复杂问题更准
- 12 人 × 80 条 = 960 条，增加 25% → 1200 条
- 3 人请假剩 9 人：1200 ÷ 9 ≈ **133** 条
- 推理模型：回答前先生成思维链，如 DeepSeek-R1
- 简单问题不必打开“深度思考”

::: notes
2022 年谷歌的研究发现，示范一步一步写出推理过程，大模型的数学题、推理题正确率明显提高，这叫思维链。每一步都简单，不容易错，错了也容易发现。
:::

# 5.6 提示词工程

## 提示词的五要素
| 要素 | 说什么 | 例子 |
|---|---|---|
| 角色 | 以什么身份做 | 十年经验的家电售后客服 |
| 任务 | 要它做什么 | 给这位顾客写一条回复 |
| 背景 | 需要知道的情况和限制 | 买了 3 个月，修过一次没修好 |
| 格式 | 形式、长度、语气 | 150 字以内，先道歉 |
| 示例 | 一两个好的样例 | 参考这条回复的语气 |

::: notes
五个要素不是每次都要写全，简单任务写清楚任务和格式就够了，越复杂、越重要的任务越要写全。
:::

## 案例：小林改写提示词
- 改写前：“帮我回复一下这个顾客。”
  - 400 多字，空话多，没提换机
- 改写后：角色 + 任务 + 背景 + 格式
  - 130 字，道歉、上门安排、换机政策都说清楚
- 只改了两个词就发出去

::: notes
课堂任务：给出一个新任务（比如写一则社区停水通知），请学生用五要素现场改写，再对比输出。
证书考点：提示词的编写和优化、对输出的评估和纠错，是人工智能训练师和生成式人工智能系统应用员（2024 年新职业）的日常工作。
:::

## 几个实用技巧
- **给例子**：想要固定的格式或风格
- **一步一步想**：复杂的计算和分析
- **拆成小任务**，**用符号把资料隔开**
- **多轮修改**：直接指出哪里不满意
- **让它说明依据**，不确定的标出来

::: notes
教材 5.6.4 节还给了总结、改写、分类、写作、学习等常用的提示词模板。
:::

# 5.7 大模型的局限与应对

## 幻觉：一本正经地胡说八道
- 编造事实、数据、人物经历
- 编造参考文献、法律条文、产品参数
- 算错数字，张冠李戴
- 原因：按概率生成，追求**通顺**而不是**正确**

::: notes
小林遇到的“国家规定空调包修六年”就是编造政策规定。课堂上请学生现场核查一条大模型回答。
:::

## 知识截止与偏见
- **知识截止**：训练数据之后的事，模型不知道
- **偏见**：学进了人类文字中的刻板印象
- **信息安全**：不把敏感信息贴进公共大模型

::: notes
偏见的例子：默认“护士”是女性、“工程师”是男性。第 9 章还会讲算法偏见。
:::

## 检索增强生成：先查资料，再回答
!mermaid 4
- 先从知识库里**检索**相关段落
- 和问题一起交给大模型
- 让回答**有依据**，能用上最新资料

::: notes
产品里的“联网搜索”也是一种检索增强生成。它能减少幻觉，但不能完全消除，仍要核查来源。
:::

## 学会核查
| 要核查的内容 | 怎样核查 |
|---|---|
| 事实和数据 | 政府网站、官方公告、统计年鉴 |
| 参考文献 | 在知网、学术搜索引擎按题目搜 |
| 法律法规、政策 | 国家法律法规数据库 |
| 计算 | 自己验算一遍 |

::: notes
小林的三条规矩：敏感信息不上传、事实必核查、人对结果负责。这三条适用于每一个在工作中使用大模型的人。
:::
