# 附录 D 术语表

本表按章节顺序列出本书的主要术语，每个术语给出英文名称、简明定义和例子。正文中带虚线下划线的术语，把鼠标停在上面就能看到定义，点击可以跳到本表。

通用术语（如“过拟合”“精确率”）的译名和定义以本系列教材共用的《系列公共术语表》为准，各书保持一致。


## 第 1 章 人工智能概述

| 术语 | 英文 | 定义 | 例子 |
|---|---|---|---|
| <span id="g-人工智能"></span>人工智能 | Artificial Intelligence, AI | 让机器具备感知、学习、推理、决策、语言交流等能力，从而完成原本需要人类智能才能完成的任务的科学和技术 | 智能调度系统根据路况和订单自动排派送路线 |
| <span id="g-图灵测试"></span>图灵测试 | Turing Test | 图灵 1950 年提出的判断方法：提问者通过文字对话分不出对方是机器还是人，就认为机器有智能 | 2025 年的三方测试中 GPT-4.5 有 73% 的时候被判为人 |
| <span id="g-中文屋"></span>中文屋 | Chinese Room | 塞尔 1980 年提出的思想实验，说明照规则处理符号、答得正确不等于真正理解 | 不懂中文的人照手册回复中文纸条 |
| <span id="g-弱人工智能"></span>弱人工智能 | Weak AI / Narrow AI | 只能在特定领域或特定任务上表现出智能的人工智能，也叫专用人工智能 | AlphaGo 只会下围棋，人脸识别系统不会翻译 |
| <span id="g-强人工智能"></span>强人工智能 | Strong AI | 在几乎所有领域都能达到甚至超过人类水平、能自主学习新事物的人工智能，目前尚未实现 | 科幻电影中无所不能的机器人 |
| <span id="g-通用人工智能"></span>通用人工智能 | Artificial General Intelligence, AGI | 强人工智能的另一种说法，强调能力的通用性 | 像人一样既会做饭、又会开车、还会写论文的 AI |
| <span id="g-达特茅斯会议"></span>达特茅斯会议 | Dartmouth Conference | 1956 年夏天在美国达特茅斯学院召开的研讨会，被看作人工智能学科诞生的标志 | 麦卡锡等人在会议计划书中首次使用“人工智能”一词 |
| <span id="g-三次浪潮"></span>三次浪潮 | Three Waves of AI | 人工智能发展中的三次高潮：推理与搜索、专家系统、机器学习与深度学习，中间隔着两次低谷 | 2016 年 AlphaGo 击败李世石发生在第三次浪潮中 |
| <span id="g-符号主义"></span>符号主义 | Symbolism | 认为智能来自用符号表示知识并按规则推理的人工智能学派 | 专家系统、知识图谱 |
| <span id="g-连接主义"></span>连接主义 | Connectionism | 认为智能来自大量简单单元相互连接、模仿人脑搭建神经网络的人工智能学派 | 深度学习、大模型 |
| <span id="g-行为主义"></span>行为主义 | Behaviorism | 认为智能在与环境的互动和“感知—行动”反馈中逐步形成的人工智能学派 | 强化学习、会走路的机器人 |
| <span id="g-数据"></span>数据 | Data | 人工智能学习规律所用的原始材料，是三要素中的“食材” | 几百万张标好名字的人脸照片 |
| <span id="g-算法"></span>算法 | Algorithm | 解决问题的一系列明确步骤，在人工智能中规定怎样学习、怎样判断，是三要素中的“菜谱” | K 近邻的“算距离、找邻居、投票” |
| <span id="g-算力"></span>算力 | Computing Power | 计算能力，常用每秒完成的运算次数衡量，是三要素中的“炉灶” | 训练 GPT-3 约需 3.14 × 10²³ 次运算 |
| <span id="g-人工智能三要素"></span>人工智能三要素 | Three Elements of AI | 数据、算法、算力三者的合称，三者同时成熟推动了今天人工智能的发展 | 2012 年 ImageNet 数据 + GPU + 新训练方法带来深度学习突破 |
| <span id="g-大模型"></span>大模型 | Large Model / Foundation Model | 用海量数据训练、参数规模巨大、能完成多种任务的人工智能模型，也叫基础模型 | DeepSeek、通义千问、文心 |
| <span id="g-生成式人工智能"></span>生成式人工智能 | Generative AI | 能生成文字、图片、声音、视频、代码等新内容的人工智能 | 大模型写通知、AI 绘画生成海报 |
| <span id="g-东数西算"></span>东数西算 | East Data West Computing | 我国 2022 年全面启动的工程，把东部数据送到西部的算力枢纽计算和存储 | 贵州、甘肃、宁夏、内蒙古等枢纽节点 |
| <span id="g-人工智能产业链"></span>人工智能产业链 | AI Industry Chain | 人工智能产业按分工形成的链条，一般分为基础层、技术层、应用层 | 芯片和数据（基础层）→ 大模型（技术层）→ 智能客服（应用层） |
| <span id="g-人工智能训练师"></span>人工智能训练师 | AI Trainer | 使用智能训练软件，在人工智能产品使用过程中进行数据库管理、算法参数设置、人机交互设计、性能测试跟踪等工作的人员 | 设计标注规范、给大模型回答打分、测试客服机器人 |

## 第 2 章 搜索、知识表示与专家系统

| 术语 | 英文 | 定义 | 例子 |
|---|---|---|---|
| <span id="g-状态"></span>状态 | State | 对问题在某一时刻情况的完整描述 | 走迷宫时人站在哪一格；下棋时棋盘上的局面 |
| <span id="g-问题求解"></span>问题求解 | Problem Solving | 把问题描述成“从初始状态出发，通过一系列动作到达目标状态”，再寻找这串动作 | 把排送货路线描述成从维修站出发、依次到达各户 |
| <span id="g-状态空间"></span>状态空间 | State Space | 一个问题所有可能的状态以及它们之间由动作连接起来的关系 | 八数码能到达的 181440 种摆法 |
| <span id="g-搜索树"></span>搜索树 | Search Tree | 从初始状态出发、逐层展开可到达状态所形成的树形结构 | 根是维修站 S，下一层是 A、B |
| <span id="g-组合爆炸"></span>组合爆炸 | Combinatorial Explosion | 问题的状态数随规模增大而急剧增长、无法逐一检查的现象 | 20 户人家的上门顺序约有 2.4 × 10¹⁸ 种 |
| <span id="g-盲目搜索"></span>盲目搜索 | Uninformed Search | 不利用目标方向等额外信息、按固定顺序展开状态的搜索方法，也叫无信息搜索 | 广度优先搜索、深度优先搜索 |
| <span id="g-广度优先搜索"></span>广度优先搜索 | Breadth-First Search, BFS | 先展开离起点近的状态、一层层向外扩展的搜索方法，能找到步数最少的路线 | 找人时先问朋友，再问朋友的朋友 |
| <span id="g-深度优先搜索"></span>深度优先搜索 | Depth-First Search, DFS | 沿一条路一直走到底、走不通再回溯的搜索方法 | 走迷宫时右手扶墙一直走 |
| <span id="g-启发函数"></span>启发函数 | Heuristic Function | 对从当前状态到目标还有多远的估计，记作 h | 直线距离、曼哈顿距离 |
| <span id="g-启发式搜索"></span>启发式搜索 | Heuristic Search | 利用启发函数决定先展开哪个状态的搜索方法 | 导航软件朝着目的地方向搜索路线 |
| <span id="g-A*-搜索"></span>A* 搜索 | A* Search | 每次展开“已走的代价 g + 估计剩余代价 h”最小的状态的启发式搜索，h 不高估时能找到最短路线 | 小地图上找到 S → B → C → G 的 9 公里路线 |
| <span id="g-博弈搜索"></span>博弈搜索 | Game Search | 在有对手、双方轮流行动的问题中寻找最好走法的搜索 | 下井字棋、国际象棋 |
| <span id="g-极小极大算法"></span>极小极大算法 | Minimax | 假设对手总选对我最不利的走法，在博弈树上自下而上取最小、最大值来选出最好一步的方法 | 在 3、2、2 中选最大的，走甲 |
| <span id="g-剪枝"></span>剪枝 | Pruning | 在搜索中跳过已知不可能更好的分支、以减少计算量的方法，常用 α-β 剪枝 | 乙的第一个应对只得 2 分，剩下的 4、6 不用算 |
| <span id="g-知识表示"></span>知识表示 | Knowledge Representation | 把人的知识用计算机能够存储和处理的形式写下来的方法 | 产生式规则、语义网络、知识图谱 |
| <span id="g-产生式规则"></span>产生式规则 | Production Rule | “如果 条件 那么 结论”形式的知识表示方法 | 如果 空调不制冷 并且 室外机不转，那么 怀疑电容故障 |
| <span id="g-语义网络"></span>语义网络 | Semantic Network | 用点表示事物或概念、用带名称的有向线表示它们之间关系的知识表示方法 | 格力 KFR-35 —是一种→ 空调 —是一种→ 家用电器 |
| <span id="g-知识图谱"></span>知识图谱 | Knowledge Graph | 以实体为节点、关系为边组织知识的图结构 | 搜索名人时右侧的知识卡片 |
| <span id="g-三元组"></span>三元组 | Triple | 知识图谱中一条知识的基本形式：（头实体，关系，尾实体）或（实体，属性，值） | （鲁迅，出生地，绍兴） |
| <span id="g-推理"></span>推理 | Reasoning | 从已知事实和知识出发，按规则推出新结论的过程 | 由“有毛发”推出“是哺乳动物” |
| <span id="g-正向推理"></span>正向推理 | Forward Reasoning | 从已知事实出发，不断执行条件已满足的规则、推出新结论的推理方式（由因到果） | 由毛发、吃肉、黄褐色、黑色条纹推出是虎 |
| <span id="g-反向推理"></span>反向推理 | Backward Reasoning | 先提出假设的结论，再寻找并验证支持它所需条件的推理方式（由果找因） | 假设是斑马，再逐个确认有蹄、有黑色条纹 |
| <span id="g-专家系统"></span>专家系统 | Expert System | 把领域专家的知识写成规则、配上推理程序，像专家一样解决问题的计算机系统 | 诊断细菌感染并推荐抗生素的 MYCIN |
| <span id="g-知识库"></span>知识库 | Knowledge Base | 专家系统中存放领域知识（主要是规则）的部分 | 动物识别的 15 条规则 |
| <span id="g-推理机"></span>推理机 | Inference Engine | 专家系统中决定使用哪条规则、按什么顺序推理的部分 | 依次检查规则、触发条件满足的规则 |

## 第 3 章 机器学习入门

| 术语 | 英文 | 定义 | 例子 |
|---|---|---|---|
| <span id="g-机器学习"></span>机器学习 | Machine Learning | 让计算机从数据中自动找出规律，并用这些规律对新数据做出判断或预测的方法 | 用十万条标好的短信训练垃圾短信识别模型 |
| <span id="g-样本"></span>样本 | Sample | 数据中的一个个体或一条记录，是机器学习的基本单位 | 奶茶店销量表中的一天、刷单识别中的一条评论 |
| <span id="g-特征"></span>特征 | Feature | 描述样本的属性，通常整理成数字，作为模型的输入 | 最高气温、星期几、是否下雨 |
| <span id="g-标签"></span>标签 | Label | 样本的正确答案，也就是希望模型学会预测的那个量 | 当天的销量、评论是“正常”还是“刷单” |
| <span id="g-模型"></span>模型 | Model | 机器学习从数据中学到的、能把特征转换成预测结果的规律 | 预测销量 ≈ 8.3 × 气温 − 33 |
| <span id="g-特征工程"></span>特征工程 | Feature Engineering | 把原始数据加工、挑选成更能反映规律的特征的过程 | 从下单时间算出“每月到店次数”“距上次到店天数” |
| <span id="g-训练集"></span>训练集 | Training Set | 用来训练模型的数据，相当于“课本和练习题” | 700 天记录中随机抽取的 560 天 |
| <span id="g-测试集"></span>测试集 | Test Set | 训练时不让模型看见、训练完成后用来评估模型的数据，相当于“期末考试卷” | 700 天记录中留出的 70 天 |
| <span id="g-验证集"></span>验证集 | Validation Set | 训练过程中用来调整参数、选择阈值的数据，相当于“模拟考试” | 再留出 70 天，用来比较几种模型方案 |
| <span id="g-泛化能力"></span>泛化能力 | Generalization | 模型在没见过的新数据上也能表现良好的能力，是评价模型最重要的标准 | 模型对上线后每天的新销量也预测得准 |
| <span id="g-监督学习"></span>监督学习 | Supervised Learning | 从带有正确答案（标签）的样本中学习规律的机器学习方式 | 用医生标注过的 X 光片训练肺炎识别模型 |
| <span id="g-无监督学习"></span>无监督学习 | Unsupervised Learning | 训练数据没有标签，由模型自己发现数据中的结构或规律的机器学习方式 | 把几千位会员自动分成几群 |
| <span id="g-自监督学习"></span>自监督学习 | Self-supervised Learning | 从数据本身自动构造标签来训练模型的方式，大模型的预训练就是一例 | 遮住一句话的最后一个词，让模型猜原词 |
| <span id="g-回归"></span>回归 | Regression | 预测一个连续数值的监督学习任务，如预测销量、房价、气温 | 根据天气预报预测明天卖多少杯奶茶 |
| <span id="g-线性回归"></span>线性回归 | Linear Regression | 用一条直线（或平面）描述特征与数值标签之间关系的回归方法 | 气温每升高 1℃，销量约多 8 杯 |
| <span id="g-误差"></span>误差 | Error | 模型预测值与真实值之间的差距 | 预测 116 杯、实际 120 杯，误差为 4 杯 |
| <span id="g-分类"></span>分类 | Classification | 预测样本属于预先定义好的哪个类别的监督学习任务 | 判断一条差评是“正常”还是“刷单” |
| <span id="g-K-近邻"></span>K 近邻 | K-Nearest Neighbors, KNN | 找出与新样本最相近的 K 个已知样本，按它们的类别投票决定新样本类别的方法 | 最近的 3 位会员中 2 位是常客，判新会员为常客 |
| <span id="g-决策树"></span>决策树 | Decision Tree | 用一连串是 / 否问题对样本逐步划分，最后得出类别或数值的模型 | 先问“账号注册是否少于 7 天”，再问“今天评价了几家店” |
| <span id="g-聚类"></span>聚类 | Clustering | 把没有标签的样本按相似程度自动分成若干组的无监督学习任务 | 把会员分成“工作日午后提神族”“周末聚会族”等 |
| <span id="g-K-均值"></span>K 均值 | K-Means | 先选 K 个中心、再交替执行“分组”和“更新中心”的聚类方法 | 到店次数 1、2、3、8、9、10 分成中心为 2 和 9 的两组 |
| <span id="g-欠拟合"></span>欠拟合 | Underfitting | 模型太简单、没学到规律，训练集和测试集成绩都差的现象 | 用直线拟合“先升后平”的销量，训练误差 16.4 杯、测试误差 20.2 杯 |
| <span id="g-过拟合"></span>过拟合 | Overfitting | 模型在训练集上表现好、在新数据上表现差的现象 | 9 次曲线训练误差为 0，测试误差却高达 943 杯 |
| <span id="g-准确率"></span>准确率 | Accuracy | 预测正确的样本占全部样本的比例 | 1000 条差评全判为正常，准确率也有 95% |
| <span id="g-类别不平衡"></span>类别不平衡 | Class Imbalance | 各类别样本数量相差很大的情况 | 1000 条差评中只有 50 条是刷单 |
| <span id="g-混淆矩阵"></span>混淆矩阵 | Confusion Matrix | 按“实际类别 × 预测类别”交叉统计样本数量的表格 | TP = 40，FN = 10，FP = 20，TN = 930 |
| <span id="g-精确率"></span>精确率 | Precision | 预测为某类的样本中，真正属于该类的比例（判得准不准） | 判为刷单的 60 条中有 40 条真是刷单，精确率约 66.7% |
| <span id="g-召回率"></span>召回率 | Recall | 某类的全部样本中，被正确找出来的比例（找得全不全） | 50 条刷单找出了 40 条，召回率 80% |
| <span id="g-阈值"></span>阈值 | Threshold | 把概率转换成类别时使用的分界值 | 刷单概率大于等于 0.5 才判为刷单 |
| <span id="g-自动机器学习"></span>自动机器学习 | Automated Machine Learning, AutoML | 自动完成选择算法、调整参数等步骤，降低机器学习使用门槛的技术，简称 AutoML | 在零代码平台上传表格，自动训练出销量预测模型 |
