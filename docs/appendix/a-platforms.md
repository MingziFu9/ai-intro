# 附录 A 在线平台与账号指南

本书没有编程实验，18 个在线体验分两类：一类是书里自带的交互动画，打开网页就能用，不用注册；另一类要用到真实的 AI 产品，比如大模型对话、AI 绘画、语音输入和智能体平台。这个附录介绍后一类产品的注册方法、免费额度、隐私设置，以及打不开时的替代办法。

!!! note "产品信息会变"
    下面的产品名称、网址和功能截至 2026 年 10 月。AI 产品更新很快，改名、改版是常事（比如阿里的“通义”App 在 2025 年 11 月改名为“千问”，百度的“文心一言”App 在 2024 年 9 月改名为“文小言”）。如果网址打不开，在手机应用商店或搜索引擎里搜公司名加“AI 助手”，认准官方出品即可。

## A.1 注册前要知道的几件事 { #a1 }

**用手机号注册**。按照我国网络实名制的要求，国内的 AI 产品基本都要用手机号注册或登录，有的还支持微信、抖音、支付宝等账号一键登录。建议用自己常用的手机号，方便以后找回对话记录。

**基础功能免费**。书中用到的大模型对话、看图说话、文字识别，在这些产品里都可以免费使用。生成图片、视频、长篇语音等耗费算力较多的功能，通常每天有一定的免费次数或“积分”，用完了第二天再用，或者换一款产品。做体验时**不需要充值，也不需要开会员**。

**电脑和手机都可以**。电脑上用浏览器打开官网，复制、截图、对比都更方便；手机上下载 App，语音输入、拍照识图更方便。同一个账号在电脑和手机上登录，对话记录是同步的。

**认准官方渠道**。搜索“某某 AI 下载”时，前几条结果可能是广告或仿冒网站，有的会诱导付费、收集个人信息。从手机自带的应用商店下载，或者直接输入下表中的官网网址。

## A.2 大模型对话产品 { #a2 }

体验 1-2、5-1、5-2、6-2 都要用到大模型对话产品。第 1 章 [1.6.1 节](../chapters/01-overview/index.md#161)介绍了它们的特点，这里列出网址：

| 产品 | 公司 | 网页版 | 书中常用的功能 |
|---|---|---|---|
| DeepSeek | 深度求索 | chat.deepseek.com | 深度思考（显示思考过程）、联网搜索、上传文件 |
| 豆包 | 字节跳动 | www.doubao.com | 语音通话、看图说话、AI 绘画、朗读 |
| 千问（原通义） | 阿里巴巴 | 在应用商店搜“千问” | 长文档阅读、看图说话、AI 绘画 |
| 文小言（原文心一言） | 百度 | 在应用商店搜“文小言” | 结合百度搜索回答问题 |
| Kimi | 月之暗面 | www.kimi.com | 长文档阅读、联网搜索 |
| 腾讯元宝 | 腾讯 | yuanbao.tencent.com | 搜索微信公众号文章 |
| 智谱清言 | 智谱 | chatglm.cn | 看图说话、智能体 |

做体验 1-2 时，从中任选 3 款即可。建议至少有一款能显示“深度思考”过程的产品，方便第 5 章讨论推理模型。

!!! tip "怎样公平地比较几款产品"
    每款产品都**新建一个对话**再提问，因为之前的对话内容会影响回答；同一个问题**原样复制**过去，不要改字；联网搜索、深度思考等开关在几款产品里保持一致（要么都开，要么都关）；同一个问题可以多问一两次，看看回答稳不稳定（第 5 章讲了为什么每次回答不一样）。

## A.3 图像与语音产品 { #a3 }

| 用途 | 可以用的产品 | 书中位置 |
|---|---|---|
| 看图说话、拍照识物 | 上表中的大多数对话产品都支持上传图片 | 体验 6-2 |
| 文字识别（OCR） | 大模型对话产品；手机相册或微信里的“提取文字”；各类扫描 App | 体验 6-2 |
| 文生图 | 即梦（字节跳动）、通义万相（阿里巴巴）、可灵（快手），以及豆包、千问等对话产品中的绘画功能 | 体验 6-2 |
| 语音识别 | 手机输入法的语音输入；讯飞听见、飞书妙记等录音转文字工具 | 体验 7-2 |
| 语音合成 | 对话产品中的“朗读”按钮；剪映等视频编辑软件的“文本朗读” | 体验 7-2 |

!!! warning "做图像和语音体验时的三个提醒"
    1. **不上传别人的脸和声音**。拍照片、录声音用你自己的，或者用没有人的场景。上传他人的照片、录音做“换脸”“克隆”，可能侵犯他人的肖像权和声音权益（第 7、9 章）。
    2. **不做语音克隆的体验**。本书只要求体验语音识别和普通的语音合成，不要求、也不建议用自己的声音做克隆，更不要克隆别人的声音。
    3. **留意 AI 生成内容的标识**。生成的图片下载后，看看有没有“AI 生成”的显式标识。按照 2025 年 9 月 1 日起施行的《人工智能生成合成内容标识办法》，转发 AI 生成的内容不能删掉标识（第 9 章）。

## A.4 智能体平台 { #a4 }

体验 8-2 要用低代码平台搭一个“课程助教”智能体，下面两个平台任选一个：

| 平台 | 网址 | 特点 |
|---|---|---|
| 扣子 | www.coze.cn | 字节跳动出品，模板和插件多，发布到豆包、飞书、微信公众号等渠道方便，适合零基础 |
| Dify | cloud.dify.ai | 开源平台，可以用官方云服务，也可以部署在学校的服务器上，数据留在本地，适合学校统一使用 |

**注册与准备**。扣子用手机号注册即可；Dify 云服务可以用邮箱或 GitHub 账号注册，如果学校部署了 Dify，用老师发的账号登录。平台都提供了入门教程，建议线下课前先花 20 分钟看一遍。

**知识库只放公开资料**。上传到知识库的文件，会存到平台的服务器上。体验 8-2 只用本教材的内容、课程安排表这类公开资料，**不要上传含有个人信息、单位内部信息的文件**。

## A.6 隐私设置 { #a6 }

注册好账号后，花两分钟做下面几件事：

1. **查看“数据用于改进模型”的开关**。不少产品默认会用你的对话来改进模型，在“设置”里找“数据管理”“隐私”“改进模型”“优化体验”等字样的选项，按自己的意愿打开或关闭。
2. **了解怎样删除对话记录**。对话列表里一般可以单条删除，设置里一般可以一键清空。课堂体验结束后，可以把含有个人信息的对话删掉。
3. **查看个性化推荐的开关**。很多 App 还有“个性化推荐”“个性化广告”的开关，按照《互联网信息服务算法推荐管理规定》，平台应当提供关闭个性化推荐的选项（第 9 章 [9.7.2 节](../chapters/09-applications-ethics/index.md#972)）。
4. **记住三条底线**：不输入敏感信息、重要信息要核查、如实说明 AI 的作用（第 1 章 [1.6.1 节](../chapters/01-overview/index.md#161)）。

## A.7 打不开怎么办 { #a7 }

| 遇到的问题 | 解决办法 |
|---|---|
| 书中的动画打不开或显示不全 | 换用电脑上的新版浏览器（Chrome、Edge、火狐或国产浏览器的“极速模式”）；手机上横过来看，或点“全屏打开” |
| 动画里的麦克风、上传图片用不了 | 浏览器会询问是否允许使用麦克风，点“允许”；不想用麦克风，可以用动画自带的示例声音和图片 |
| 某款 AI 产品打不开、注册不了 | 换 A.2 节表中的另一款，体验的要求都能完成；记录表里写明你用的是哪款产品 |
| 免费次数用完了 | 第二天再做，或者换一款产品；不要为了做作业充值 |
| 回答很慢或提示“服务繁忙” | 避开晚上的高峰时段；关掉“深度思考”再试 |
| 学校网络屏蔽了某个网站 | 用手机流量，或者课后在家里做；线下课上的体验，老师会提前准备好可用的平台 |
