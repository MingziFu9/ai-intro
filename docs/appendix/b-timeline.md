# 附录 B 人工智能大事年表

这份年表按第 1 章 [1.2 节](../chapters/01-overview/index.md#12)的四个阶段，列出人工智能发展中的关键事件，最后一列是书中讲到它的地方。第 1 章的交互动画[“AI 发展时间线”](../sims/ai-timeline/main.html){ target=_blank }挑出了其中最重要的 18 件，可以配合着看。

!!! tip "怎样读这份年表"
    不必死记年份。读的时候注意三件事：每一次热潮靠的是什么方法（推理、知识、数据还是算力）；每一次低谷的原因是什么；我国在哪些时候、以什么方式参与进来。读完后，可以试着用自己的话讲一讲“人工智能的三起两落”。

## B.1 萌芽与第一次热潮（1943—1973） { #b1 }

| 年份 | 事件 | 书中位置 |
|---|---|---|
| 1943 | 麦卡洛克和皮茨提出人工神经元的数学模型，这是神经网络的起点 | 第 4 章 |
| 1950 | 图灵发表《计算机器与智能》，提出“图灵测试” | 1.1.2 |
| 1956 | 达特茅斯会议召开，“人工智能”一词正式出现，这一年被称为人工智能元年 | 1.2.1 |
| 1958 | 罗森布拉特提出感知机 | 第 4 章 |
| 1959 | 塞缪尔用“机器学习”一词描述他的跳棋程序，这个程序能通过自我对弈越下越好 | 第 3 章 |
| 1965 | 世界上第一个专家系统 DENDRAL 开始研制，用于推断化合物的分子结构 | 1.2.3 |
| 1966 | 魏森鲍姆的聊天程序 ELIZA 问世 | 1.1.2、1.2.2 |
| 1969 | 明斯基等人在《感知机》一书中指出单层感知机连“异或”都学不会，神经网络研究陷入低潮 | 第 4 章 |
| 1973 | 英国的一份评估报告认为人工智能没有实现承诺，英美大幅削减经费，**第一次低谷**开始 | 1.2.2 |

## B.2 专家系统与第二次热潮（1974—1993） { #b2 }

| 年份 | 事件 | 书中位置 |
|---|---|---|
| 20 世纪 70 年代 | 医疗诊断专家系统 MYCIN 研制成功，能给出细菌感染的诊断和用药建议 | 第 2 章 |
| 1980 | 用于配置计算机订单的专家系统 XCON 投入使用，专家系统走向商业 | 1.2.3 |
| 1982 | 日本启动“第五代计算机”国家计划，最终没有达到目标 | 1.2.3 |
| 1986 | 鲁梅尔哈特、辛顿、威廉姆斯发表反向传播算法的论文，多层神经网络可以训练了 | 第 4 章 |
| 1987 | 专用人工智能计算机市场崩溃，专家系统维护成本高、难以扩展，**第二次低谷**开始 | 1.2.3 |
| 1989 | 杨立昆用卷积神经网络识别手写的邮政编码 | 第 4、6 章 |

## B.3 机器学习兴起与深度学习突破（1993—2021） { #b3 }

| 年份 | 事件 | 书中位置 |
|---|---|---|
| 1997 | IBM 的“深蓝”战胜国际象棋世界冠军卡斯帕罗夫 | 第 2 章 |
| 1998 | 卷积神经网络 LeNet-5 用于银行支票的手写数字识别 | 第 4、6 章 |
| 2006 | 辛顿等人提出训练深层网络的新方法，“深度学习”一词开始流行 | 1.2.4 |
| 2009 | 李飞飞团队发布 ImageNet 图像数据集，后来每年举办图像识别比赛 | 第 6 章 |
| 2011 | IBM 的“沃森”在美国电视智力竞赛中战胜人类冠军；苹果手机推出语音助手 Siri | — |
| 2012 | AlexNet 在 ImageNet 比赛中把错误率从约 26% 降到约 15%，**深度学习时代**到来 | 1.2.4、第 4 章 |
| 2014 | 生成对抗网络（GAN）提出，AI 开始能“画”出逼真的图片 | — |
| 2015 | 残差网络 ResNet 在 ImageNet 上的识别错误率低于人类的水平 | 第 6 章 |
| 2016 | AlphaGo 以 4∶1 战胜围棋世界冠军李世石；百度开源深度学习框架飞桨 | 第 8 章、第 4 章 |
| 2017 | 谷歌提出 **Transformer**；AlphaGo Zero 不用人类棋谱，自学成才；国务院印发《新一代人工智能发展规划》 | 第 5 章、第 8 章 |
| 2018 | BERT、GPT 等预训练语言模型发布，“预训练 + 微调”成为自然语言处理的主流做法 | 第 5 章 |
| 2020 | GPT-3 发布，有 1750 亿个参数；AlphaFold 2 在蛋白质结构预测上取得突破；华为开源深度学习框架昇思 | 第 5 章、第 9 章、第 4 章 |
| 2021 | 我国发布《新一代人工智能伦理规范》 | 9.3 |

## B.4 大模型时代（2022 年至今） { #b4 }

| 时间 | 事件 | 书中位置 |
|---|---|---|
| 2022 年 2 月 | “东数西算”工程全面启动 | 1.4.3、9.6.2 |

| 2022 年 11 月 | ChatGPT 发布，两个月用户超过 1 亿，人工智能进入**大模型时代** | 1.2.5 |

| 2023 年 8 月 15 日 | 《生成式人工智能服务管理暂行办法》施行 | 第 5、9 章 |

| 2024 年 4 月 | 北京互联网法院就一起 AI 声音侵权案作出判决，认定声音权益及于 AI 生成的声音 | 第 7 章 |

!!! note "年表之外"
    年表只列出了少数里程碑。人工智能的进步，更多是成千上万的研究者、工程师日复一日的积累，以及数据标注员、训练师等岗位上无数普通劳动者的贡献。你学完这门课、走上工作岗位，也可能成为这段历史的一部分。
