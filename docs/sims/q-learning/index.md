## 教学说明

**学习目标**

1. 能在格子世界中指出智能体、环境、状态、动作、奖励和策略（记忆）；
2. 能按公式手算一次 Q 值更新，说明 Q 值怎样从宝藏往回传（应用）；
3. 能比较不同探索率和奖励设置下的学习效果（分析）。

**画面与操作**

- 4 张地图：空旷的房间、有陷阱、绕过墙、悬崖边。🏠 是起点，💎 是宝藏，🔥 是陷阱，深灰色是墙。
- 每个格子里四个三角形分别是往上、右、下、左走的 Q 值，绿色为正、红色为负，颜色越深绝对值越大；黑色箭头指向目前 Q 值最大的方向。鼠标停在格子上可以看到具体的 Q 值。
- “走一步”显示这一步是探索还是利用，以及 Q 值的计算式；“走完一回合”动画走完一回合；“训练 50 回合”快速训练；“按学到的路线走”不再探索，按 Q 值最大的方向走一遍；“清空记忆”把所有 Q 值清零。
- 右侧可以调节探索率、学习率、折扣因子和三种奖励；下方柱状图是每回合用的步数（每回合最多 100 步）。

**说明**：使用标准的 Q 学习更新规则，Q 值初始为 0，撞墙或出界时留在原地并照常扣分。由于有随机探索，每次训练的结果略有不同。

**课堂用法建议**

1. 先只点“走一步”，请学生跟着手算第一次碰到宝藏时的 Q 值更新，体会“好消息从宝藏往回传”。
2. 分组比较 ε = 0、0.2、0.8 时训练 200 回合的效果，讨论探索与利用。
3. 把“每走一步”的奖励改成 0，观察路线变化，引出“你奖励什么，它就学什么”。
4. 在“悬崖边”上讨论：为什么有探索时，贴着悬崖走反而危险？对应现实中“训练时的试错不能在真实世界里做”。
