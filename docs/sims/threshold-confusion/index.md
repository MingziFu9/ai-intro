## 教学说明

本动画来自《自然语言处理导论》第 6 章，在本书中用来理解混淆矩阵和“精确率与召回率此消彼长”。

**学习目标**

1. 能读懂混淆矩阵的四个格子，并算出准确率、精确率、召回率（应用）；
2. 能说出阈值调高、调低时，精确率和召回率分别怎样变化（理解）；
3. 能根据“宁可错抓、不可漏掉”或“宁可漏掉、不可错抓”的业务需求选阈值（评价）。

**画面与操作**

- 左侧直方图：横轴是模型给出的“好评概率”，红色是实际差评、绿色是实际好评；竖线是阈值，可以拖动，也可以用滑块和场景按钮调整。
- 右侧：以“差评”为正类的混淆矩阵和各项指标。
- 底部：离阈值最近的几条评论，拖动阈值时可以看到它们的判断怎样翻转。

**数据来源**：《自然语言处理导论》实验 6-2 中，模型对 2398 条外卖评论（其中差评 1598 条）的实际预测概率。阈值为 0.5 时 TP = 1528、FN = 70、FP = 221、TN = 579，与本书 3.8 节的表格一致。

**课堂用法建议**

1. 先问学生：“阈值从 0.5 调到 0.7，被判为差评的评论会变多还是变少？”再拖动验证；
2. 让学生找出准确率最高的阈值，再讨论“准确率最高是不是就最好”；
3. 联系 3.8 节的“漏诊与误诊”例子，说说医院筛查和垃圾短信拦截分别该把阈值往哪边调。
