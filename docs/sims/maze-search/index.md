## 教学说明

**学习目标**

1. 能描述广度优先“一层层扩”、深度优先“一条路走到底”、A* “朝着目标去”的展开方式（理解）；
2. 能根据展开格子数和路线长度，比较三种方法的效率和结果（分析）；
3. 能说明启发函数（曼哈顿距离）为什么能让搜索少走冤枉路（理解）。

**画面与操作**

- 上方选择搜索方法；“自动运行”连续展开，“走一步”每次展开一个格子，“重置”从头开始。
- 浅蓝色是已展开的格子，浅黄色是待展开的格子，橙色是找到的路线。下方统计展开格子数、路线长度和待展开格子数。
- 点空白格子加墙、点墙去掉；“换一个迷宫”在 3 个预设迷宫间切换，“清空墙壁”变成空地。

**说明**：每步代价为 1，所以广度优先和 A* 找到的都是最短路线。深度优先的方向顺序固定为上、右、下、左；A* 的启发函数是曼哈顿距离，f 相同时先展开 h 小的格子。

**课堂用法建议**

1. 先运行广度优先，请学生描述“浅蓝色怎样扩散”，再运行 A*，对比扩散的形状；
2. 在“迷宫 3（有一道长墙）”上运行 A*，观察它先朝终点冲、碰墙后才绕路，讨论启发函数“估计”的含义；
3. 让学生自己设计一个迷宫，让深度优先找到的路线尽可能长。
