## 教学说明

**学习目标**

1. 能根据训练误差和测试误差判断模型是欠拟合、刚好还是过拟合（分析）；
2. 能解释为什么不能只看训练集上的成绩（理解）。

**画面与操作**

- 上图：蓝点是训练集，橙点是测试集，黑色曲线是模型在训练集上学到的预测曲线。
- 滑块把模型从 1 次（直线）调到 9 次多项式，次数越高，曲线越弯、越“灵活”。
- 左下显示本次的训练误差和测试误差；右下是两种误差随复杂度变化的曲线，阴影是当前位置。

**数据来源**：编者构造的 22 天“气温—奶茶销量”数据，规律是“气温越高销量越高，过了 33℃ 后增长放缓”，再加上随机波动。拟合用最小二乘法事先算好，页面上的误差与教材 3.7 节的表格一致：1 次 16.4 / 20.2，2 次 10.1 / 9.0，9 次 0.0 / 943.4（训练 / 测试，单位：杯）。

**课堂用法建议**

1. 先只让学生看蓝点，问“哪条曲线最好”，多数人会选穿过所有点的那条；再打开测试误差揭晓答案；
2. 让学生找到测试误差最小的次数，并用“背答案”和“举一反三”解释；
3. 追问：除了换简单模型，还有什么办法能减轻过拟合（多收集数据、留出验证集）。
